# YiErBuBu V2.3

Windows 版一二和布布桌宠，面向“更像抖音截图成品”的视觉还原版本。

## 这版重点
- 左侧布布（棕色）负责鼠标
- 右侧一二（白色）负责紧凑型键盘
- 保留逐键高亮与多键同时按下
- 重新设计整体构图、角色比例、桌边线、键盘与鼠标外观
- 桌宠主体不放控制按钮，控制入口保留在系统托盘

## 仍然不是最终正式素材的部分
- 本版仍采用纯 WPF 绘制角色，不是外部 PNG 分层美术
- 但风格与布局已更贴近参考截图

## GitHub 使用方式
1. 建议在现有仓库中新建分支，例如 `v2-3-visual`。
2. 上传本压缩包解压后的全部文件，覆盖旧版工程。
3. 运行 GitHub Actions 中的 `Build Windows EXE`。
4. 下载 Artifacts 中的 EXE 压缩包并测试。

## 测试重点
- 是否能正常编译
- 左边布布是否只响应鼠标
- 右边一二是否只响应键盘
- 键帽是否按下高亮
- 整体风格是否比 V2.1 更接近截图
